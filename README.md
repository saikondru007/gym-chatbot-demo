# IronWorks Gym — AI Chatbot Demo

A fictional gym homepage ("IronWorks Gym", Dallas, TX) with an embedded AI chat assistant, built as a portfolio piece to showcase what an AI chatbot can do for a small business website.

## What it does

- **Fictional business site** — hero, membership plans (Day pass $15 / Monthly $39 / Annual $390), weekly class schedule (yoga, HIIT, spin, strength), trainer profiles, hours/location/contact sections. Fully responsive, mobile-friendly.
- **"Flex" AI coach widget** — floating chat bubble (bottom-right) with typing animation, quick-reply chips, and an energetic gym-coach personality.
- **FAQ answering** — hours (daily 5am–11pm), location, membership prices, guest policy, class schedule, trainers, amenities (sauna, pool, smoothie bar), personal training.
- **Plan recommender** — asks the visitor's fitness goal (lose weight / build muscle / general fitness) and training frequency, then recommends the right membership with reasoning.
- **Free trial signup** — multi-step flow collecting name, phone, email, and preferred day, with validation and a confirmation reference number.
- **Personal-training lead capture** — collects name, phone, and training goal for coach follow-up.

## Tech

Single self-contained `index.html` — inline CSS and vanilla JS, zero external dependencies, works offline. The "AI" is a compact keyword/intent-based response engine with multi-step conversation flows; no backend or API keys needed. No third-party branding anywhere on the page.

*Demo only — IronWorks Gym is a fictional business.*
